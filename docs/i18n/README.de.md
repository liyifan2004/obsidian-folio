## 📖 Übersicht

**Folio** erstellt eine synchronisierte Zwei-Fenster-Leseumgebung in Obsidian:

- **Linker Bereich**: Nativer Obsidian-Editor/Vorschau, vollständig bearbeitbar
- **Rechter Bereich**: Automatisch geteilte Ansicht zeigt die Fortsetzung des Inhalts
- **Bidirektionales Scrollen**: Scrollen Sie entweder Fenster, das andere folgt automatisch
- **Modus-Anpassung**: Nahtloses Wechseln zwischen Bearbeiten- und Vorschaumodus

---

## ✨ Funktionen

### 🔄 Bidirektionale Synchronisation
- Linken Bereich scrollen → Rechter Bereich folgt und zeigt Fortsetzung
- Rechten Bereich scrollen → Linker Bereich folgt und zeigt vorherigen Inhalt
- Flüssige 60fps-Scroll-Leistung

### ⚙️ Anpassbare Überlappung
- Anzahl der überlappenden Zeilen zwischen Bereichen anpassen (0-10 Zeilen)
- Verhindert, dass die Symbolleiste Inhalte verdeckt
- Standard: 2 Zeilen Überlappung

---

## 🚀 Installation

### Aus der Obsidian Community Plugins

1. **Einstellungen** → **Community-Plugins** öffnen
2. **Sicherer Modus** deaktivieren
3. Auf **Durchsuchen** klicken und "Folio" suchen
4. Auf **Installieren** klicken
5. Plugin aktivieren

---

## 🎯 Verwendung

### Schnellstart

1. Öffnen Sie eine beliebige Markdown-Notiz in Obsidian
2. Klicken Sie auf das **📑 Symbol** im linken Menüband
3. Der rechte Bereich teilt sich automatisch und folgt dem Scrollen
