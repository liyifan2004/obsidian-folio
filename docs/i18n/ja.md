# デュアルペイン同期ビュー

双ペインまたは三ペインの同期読み書き体験を実現する Obsidian プラグイン。現在の画面と隣接するコンテンツを同時に表示し、完璧な同期スクロールを実現します。

## ✨ 機能

### 📖 2ペインモード
- 左側に**メインエディタ**
- 右側に**次の画面**を表示
- 同期スクロール
- 連続読みに最適

### 📚 3ペインモード
- 左側に**前の画面**を表示
- 中央に**メインエディタ**
- 右側に**次の画面**を表示
- 編集時に完全なコンテキスト認識
- 前後の内容を常に把握

### ⚡ スマート同期
- リアルタイム双方向スクロール同期
- 編集、プレビュー、ソースモードに対応
- ペイン間の重複行数を調整可能（0-10行）
- シームレスなモード切り替え

### 🎮 簡単な操作
- ツールバーアイコンからモード選択メニュー
- クイックキーボードショートカット
- ワンクリックモード切り替え
- ペインを閉じたときの自動クリーンアップ

## 📦 インストール

### Obsidian コミュニティプラグインから
1. 設定 → コミュニティプラグインを開く
2. "Dual Pane Sync View" を検索
3. インストールして有効化

### 手動インストール
1. GitHub から最新リリースをダウンロード
2. `.obsidian/plugins/` に展開
3. 設定 → コミュニティプラグインで有効化

## 🚀 使い方

### ツールバーメニュー
左ツールバーの ◪ アイコンをクリックしてモード選択メニューを開きます：

- **2ペインモード** - メイン + 右フォロワー
- **3ペインモード** - 左 + メイン + 右フォロワー
- **停止** - すべてのフォロワーペインを閉じる

### コマンド
すべてのコマンドはコマンドパレット（Ctrl/Cmd + P）で見つかります：

| コマンド | 説明 |
|---------|-------------|
| 2ペインモードを切り替え | 2ペインモードの有効/無効 |
| 3ペインモードを切り替え | 3ペインモードの有効/無効 |
| 同期読み込みを停止 | すべてのフォロワーペインを閉じる |
| 両方のペインを1ページ上へ | 1ページ分上にスクロール |
| 両方のペインを1ページ下へ | 1ページ分下にスクロール |
| 両方のペインを2ページ上へ | 2ページ分上にスクロール |
| 両方のペインを2ページ下へ | 2ページ分下にスクロール |

### 推奨ホットキー
- **2ペインモード**: `Ctrl/Cmd + Shift + D`
- **3ペインモード**: `Ctrl/Cmd + Shift + T`
- **停止**: `Ctrl/Cmd + Shift + Q`
- **1ページ上へ**: `Ctrl/Cmd + ↑`
- **1ページ下へ**: `Ctrl/Cmd + ↓`

## ⚙️ 設定

### コンテンツの重複
ペイン間の重複行数を調整（0-10行）：
- **0**: 重複なし、きれいなページ区切り
- **2-3**: 推奨、スムーズな読み
- **5-10**: より多くのコンテキスト連続性

### 言語
インターフェース言語は Obsidian の設定から自動検出されます。

## 🎯 ユースケース

### 執筆時
- 執筆中に前文を参照
- 次のセクションをプレビュー
- 長文書での一貫性を維持

### 読書時
- ページめくりなしで連続読み
- シームレスなスクロール体験
- 小説や長文記事に最適

### 翻訳時
- 左側に原文
- 右側に訳文
- 作業中に次のセクションを参照

### 校閲時
- セクションを並べて比較
- 完全な文書コンテキスト
- 効率的な校正ワークフロー
