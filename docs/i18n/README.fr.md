## 📖 Aperçu

**Vue Double Panneau Synchronisée** crée un environnement de lecture double panneau synchronisé dans Obsidian :

- **Panneau gauche** : Éditeur/aperçu natif Obsidian, entièrement éditable
- **Panneau droit** : Vue fractionnée automatique affichant la suite du contenu
- **Défilement bidirectionnel** : Faites défiler l'un ou l'autre panneau, l'autre suit automatiquement
- **Adaptation de mode** : Basculez sans problème entre les modes édition et aperçu

---

## ✨ Fonctionnalités

### 🔄 Synchronisation Bidirectionnelle
- Faites défiler le panneau gauche → Le panneau droit suit en affichant la suite
- Faites défiler le panneau droit → Le panneau gauche suit en affichant le contenu précédent
- Performance de défilement fluide à 60ips

### ⚙️ Chevauchement Personnalisable
- Ajustez le nombre de lignes qui se chevauchent entre les panneaux (0-10 lignes)
- Empêche la barre d'outils de masquer le contenu
- Par défaut : 2 lignes de chevauchement

---

## 🚀 Installation

### Depuis les Plugins Communautaires Obsidian

1. Ouvrez **Paramètres** → **Plugins communautaires**
2. Désactivez le **Mode sécurisé**
3. Cliquez sur **Parcourir** et recherchez "Vue Double Panneau Synchronisée"
4. Cliquez sur **Installer**
5. Activez le plugin

---

## 🎯 Utilisation

### Démarrage Rapide

1. Ouvrez n'importe quelle note Markdown dans Obsidian
2. Cliquez sur l'**icône 📑** dans le ruban gauche
3. Le panneau droit se divise automatiquement et suit votre défilement

---

## ⚙️ Paramètres

| Paramètre | Description | Défaut |
|-----------|-------------|--------|
| **Lignes de chevauchement** | Nombre de lignes qui se chevauchent entre les panneaux | 2 |
