## 📖 概述

**Folio** 在 Obsidian 中創建一個同步的雙欄閱讀環境：

- **左側視窗**：原生 Obsidian 編輯器/預覽，完全可編輯
- **右側視窗**：自動分割顯示，接續左側內容
- **雙向滾動**：滾動任意一側，另一側自動跟隨
- **模式自適應**：無縫切換編輯和預覽模式

非常適合閱讀長文件、對比不同章節，或編輯時參考前文內容。

---

## ✨ 功能特性

### 🔄 雙向同步
- 滾動左側視窗 → 右側視窗跟隨顯示接續內容
- 滾動右側視窗 → 左側視窗跟隨顯示前文內容
- 流暢的 60fps 滾動性能

### 📝 完全原生編輯
- 左側視窗保持完全可編輯，使用所有 Obsidian 功能
- 所有挿件正常工作（Vim 模式、主題等）
- 語法突顯和即時預覽

### ⚙️ 可自定義重合
- 調整視窗間重合行數（0-10 行）
- 防止工具欄遮擋內容
- 預設：2 行重合

## 🚀 安裝

### 從 Obsidian 社群挿件安裝

1. 開啟 **設定** → **第三方挿件**
2. 關閉 **安全模式**
3. 點擊 **瀏覽** 並搜尋 "Folio"
4. 點擊 **安裝**
5. 啟用挿件

### 手動安裝

1. 從 [GitHub Releases](https://github.com/liyifan2004/obsidian-folio/releases) 下載最新版本
2. 解壓縮檔案到挿件資料夾：`<vault>/.obsidian/plugins/obsidian-dual-pane-sync/`
3. 重新載入 Obsidian
4. 在 **設定** → **第三方挿件** 中啟用挿件

## 🎯 使用方法

### 快速開始

1. 在 Obsidian 中開啟任意 Markdown 筆記
2. 點擊左側功能區的 **📑 圖示**
3. 右側視窗自動分割並跟隨你的滾動

### 快捷鍵配置

1. 開啟 **設定** → **快捷鍵**
2. 搜尋 "Folio"
3. 綁定你喜歡的按鍵

**推薦快捷鍵：**
- `Page Up` / `Page Down`
- `Ctrl + ↑` / `Ctrl + ↓`
- `Cmd + ↑` / `Cmd + ↓` (Mac)
