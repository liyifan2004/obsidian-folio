# Vista de Sincronización de Dos Paneles

Un plugin de Obsidian que permite una experiencia de lectura/escritura sincronizada en dos o tres paneles. Visualice la pantalla actual y el contenido adyacente simultáneamente con desplazamiento perfectamente sincronizado.

## ✨ Características

### 📖 Modo 2 Paneles
- **Editor principal** a la izquierda
- **Pantalla siguiente** a la derecha
- Desplazamiento sincronizado
- Perfecto para lectura continua

### 📚 Modo 3 Paneles
- **Pantalla anterior** a la izquierda
- **Editor principal** en el centro
- **Pantalla siguiente** a la derecha
- Conciencia completa del contexto mientras edita
- Vea lo que viene antes y después de su posición actual

### ⚡ Sincronización Inteligente
- Sincronización bidireccional de desplazamiento en tiempo real
- Compatible con modos Editar, Vista previa y Fuente
- Superposición ajustable entre paneles (0-10 líneas)
- Cambio de modo sin interrupciones

### 🎮 Controles Fáciles
- Icono de barra de herramientas con menú de selección de modo
- Atajos de teclado rápidos
- Cambio de modo con un clic
- Limpieza automática al cerrar paneles

## 📦 Instalación

### Desde los Plugins Comunitarios de Obsidian
1. Abrir Ajustes → Plugins de la comunidad
2. Buscar "Dual Pane Sync View"
3. Instalar y Habilitar

### Instalación Manual
1. Descargar la última versión desde GitHub
2. Extraer a `.obsidian/plugins/`
3. Habilitar en Ajustes → Plugins de la comunidad

## 🚀 Uso

### Menú de la Barra de Herramientas
Haga clic en el icono ◪ en la barra de herramientas izquierda para abrir el menú de selección de modo:

- **Modo 2 Paneles** - Principal + Seguidor derecho
- **Modo 3 Paneles** - Izquierdo + Principal + Seguidor derecho
- **Detener** - Cerrar todos los paneles seguidores

### Comandos
Todos los comandos se pueden encontrar en la Paleta de comandos (Ctrl/Cmd + P):

| Comando | Descripción |
|---------|-------------|
| Alternar modo 2 paneles | Habilitar/deshabilitar vista de dos paneles |
| Alternar modo 3 paneles | Habilitar/deshabilitar vista de tres paneles |
| Detener lectura sincronizada | Cerrar todos los paneles seguidores |
| Página anterior (ambos paneles) | Desplazar hacia arriba una página |
| Página siguiente (ambos paneles) | Desplazar hacia abajo una página |
| Dos páginas arriba | Desplazar hacia arriba dos páginas |
| Dos páginas abajo | Desplazar hacia abajo dos páginas |

### Atajos Recomendados
- **Modo 2 Paneles**: `Ctrl/Cmd + Shift + D`
- **Modo 3 Paneles**: `Ctrl/Cmd + Shift + T`
- **Detener**: `Ctrl/Cmd + Shift + Q`
- **Página anterior**: `Ctrl/Cmd + ↑`
- **Página siguiente**: `Ctrl/Cmd + ↓`

## ⚙️ Ajustes

### Superposición de Contenido
Ajuste el número de líneas de superposición entre paneles (0-10 líneas):
- **0**: Sin superposición, saltos de página limpios
- **2-3**: Recomendado, lectura fluida
- **5-10**: Más continuidad de contexto

### Idioma
El idioma de la interfaz se detecta automáticamente desde los ajustes de Obsidian.

## 🎯 Casos de Uso

### Para Escritores
- Ver contexto anterior mientras escribe
- Previsualizar secciones próximas
- Mantener el flujo narrativo en documentos largos

### Para Lectores
- Leer sin interrupciones de cambio de página
- Experiencia de desplazamiento sin interrupciones
- Perfecto para novelas y artículos largos

### Para Traductores
- Texto fuente a la izquierda
- Traducción a la derecha
- Referenciar la siguiente sección mientras trabaja

### Para Revisores
- Comparar secciones lado a lado
- Contexto completo del documento
- Flujo de trabajo de corrección eficiente
