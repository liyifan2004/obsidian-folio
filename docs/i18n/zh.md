# 双栏同步视图

一个 Obsidian 插件，提供双栏或三栏同步阅读/写作体验。同时查看当前屏幕和相邻内容，实现完美同步滚动。

## ✨ 功能特点

### 📖 双栏模式
- 左侧**主编辑器**
- 右侧显示**后一屏**内容
- 同步滚动
- 适合连续阅读

### 📚 三栏模式
- 左侧显示**前一屏**内容
- 中间**主编辑器**
- 右侧显示**后一屏**内容
- 编辑时拥有完整的上下文感知
- 随时了解前后文内容

### ⚡ 智能同步
- 实时双向滚动同步
- 支持编辑、预览和源码模式
- 可调整窗格间重叠行数（0-10行）
- 无缝模式切换

### 🎮 便捷控制
- 工具栏图标菜单选择模式
- 快速键盘快捷键
- 一键模式切换
- 关闭窗格时自动清理

## 📦 安装方法

### 从 Obsidian 社区插件
1. 打开 设置 → 社区插件
2. 搜索 "Dual Pane Sync View"
3. 安装并启用

### 手动安装
1. 从 GitHub 下载最新版本
2. 解压到 `.obsidian/plugins/`
3. 在 设置 → 社区插件 中启用

## 🚀 使用方法

### 工具栏菜单
点击左侧工具栏的 ◪ 图标打开模式选择菜单：

- **双栏模式** - 主窗口 + 右跟随窗口
- **三栏模式** - 左跟随 + 主窗口 + 右跟随
- **停止** - 关闭所有跟随窗口

### 命令
所有命令可在命令面板中找到（Ctrl/Cmd + P）：

| 命令 | 说明 |
|------|------|
| 切换双栏模式 | 启用/禁用双栏视图 |
| 切换三栏模式 | 启用/禁用三栏视图 |
| 停止同步阅读 | 关闭所有跟随窗口 |
| 双栏上翻页 | 两个窗口同时向上滚动一页 |
| 双栏下翻页 | 两个窗口同时向下滚动一页 |
| 双栏上翻两页 | 向上滚动两页 |
| 双栏下翻两页 | 向下滚动两页 |

### 推荐快捷键
- **双栏模式**: `Ctrl/Cmd + Shift + D`
- **三栏模式**: `Ctrl/Cmd + Shift + T`
- **停止**: `Ctrl/Cmd + Shift + Q`
- **上翻页**: `Ctrl/Cmd + ↑`
- **下翻页**: `Ctrl/Cmd + ↓`

## ⚙️ 设置选项

### 内容重叠
调整窗格之间的重叠行数（0-10行）：
- **0**: 无重叠，干净的翻页
- **2-3**: 推荐值，流畅阅读
- **5-10**: 更多上下文连续性

### 语言
界面语言自动从 Obsidian 设置中检测。

## 🎯 使用场景

### 写作时
- 写作时查看前文
- 预览后续章节
- 在长篇文档中保持叙述连贯

### 阅读时
- 无需翻页即可连续阅读
- 无缝滚动体验
- 适合阅读小说和长篇文章

### 翻译时
- 左侧原文
- 右侧译文
- 工作时参考下一节内容

### 审校时
- 并排比较章节
- 完整文档上下文
- 高效的校对流程
