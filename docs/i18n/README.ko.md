## 📖 개요

**Folio**는 Obsidian에서 동기화된 다중 열 독서 환경을 생성합니다:

- **왼쪽 패널**: 기본 Obsidian 편집기/미리보기, 완전히 편집 가능
- **오른쪽 패널**: 자동 분할 표시, 왼쪽 콘텐츠의 계속 표시
- **양방향 스크롤**: 어느 쪽이든 스크롤하면 다른 쪽이 자동으로 따라감
- **모드 적응**: 편집 모드와 미리보기 모드를 원활하게 전환

---

## ✨ 기능

### 🔄 양방향 동기화
- 왼쪽 패널 스크롤 → 오른쪽 패널이 계속 표시하며 따라감
- 오른쪽 패널 스크롤 → 왼쪽 패널이 이전 내용을 표시하며 따라감
- 부드러운 60fps 스크롤 성능

### ⚙️ 사용자 정의 가능한 중첩
- 패널 간 중첩 줄 수 조정 (0-10 줄)
- 도구 모음이 콘텐츠를 가리는 것 방지
- 기본값: 2 줄 중첩

---

## 🚀 설치

### Obsidian 커뮤니티 플러그인에서

1. **설정** → **커뮤니티 플러그인** 열기
2. **안전 모드** 끄기
3. **찾아보기** 클릭하고 "Folio" 검색
4. **설치** 클릭
5. 플러그인 활성화

---

## 🎯 사용법

### 빠른 시작

1. Obsidian에서 Markdown 노트 열기
2. 왼쪽 리본의 **📑 아이콘** 클릭
3. 오른쪽 패널이 자동으로 분할되어 스크롤을 따라감
