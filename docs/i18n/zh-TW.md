# 雙欄同步檢視

一個 Obsidian 外掛，提供雙欄或三欄同步閱讀/寫作體驗。同時檢視目前畫面和相鄰內容，實現完美同步捲動。

## ✨ 功能特點

### 📖 雙欄模式
- 左側**主編輯器**
- 右側顯示**後一屏**內容
- 同步捲動
- 適合連續閱讀

### 📚 三欄模式
- 左側顯示**前一屏**內容
- 中間**主編輯器**
- 右側顯示**後一屏**內容
- 編輯時擁有完整的上下文感知
- 隨時了解前後文內容

### ⚡ 智慧同步
- 即時雙向捲動同步
- 支援編輯、預覽和原始碼模式
- 可調整窗格間重疊行數（0-10行）
- 無縫模式切換

### 🎮 便捷控制
- 工具列圖示選單選擇模式
- 快速鍵盤快捷鍵
- 一鍵模式切換
- 關閉窗格時自動清理

## 📦 安裝方法

### 從 Obsidian 社群外掛
1. 開啟 設定 → 社群外掛
2. 搜尋 "Dual Pane Sync View"
3. 安裝並啟用

### 手動安裝
1. 從 GitHub 下載最新版本
2. 解壓縮到 `.obsidian/plugins/`
3. 在 設定 → 社群外掛 中啟用

## 🚀 使用方法

### 工具列選單
點擊左側工具列的 ◪ 圖示開啟模式選擇選單：

- **雙欄模式** - 主視窗 + 右跟隨視窗
- **三欄模式** - 左跟隨 + 主視窗 + 右跟隨
- **停止** - 關閉所有跟隨視窗

### 命令
所有命令可在命令面板中找到（Ctrl/Cmd + P）：

| 命令 | 說明 |
|------|------|
| 切換雙欄模式 | 啟用/停用雙欄檢視 |
| 切換三欄模式 | 啟用/停用三欄檢視 |
| 停止同步閱讀 | 關閉所有跟隨視窗 |
| 雙欄上翻頁 | 兩個視窗同時向上捲動一頁 |
| 雙欄下翻頁 | 兩個視窗同時向下捲動一頁 |
| 雙欄上翻兩頁 | 向上捲動兩頁 |
| 雙欄下翻兩頁 | 向下捲動兩頁 |

### 推薦快捷鍵
- **雙欄模式**: `Ctrl/Cmd + Shift + D`
- **三欄模式**: `Ctrl/Cmd + Shift + T`
- **停止**: `Ctrl/Cmd + Shift + Q`
- **上翻頁**: `Ctrl/Cmd + ↑`
- **下翻頁**: `Ctrl/Cmd + ↓`

## ⚙️ 設定選項

### 內容重疊
調整窗格之間的重疊行數（0-10行）：
- **0**: 無重疊，乾淨的翻頁
- **2-3**: 推薦值，流暢閱讀
- **5-10**: 更多上下文連續性

### 語言
介面語言自動從 Obsidian 設定中檢測。

## 🎯 使用場景

### 寫作時
- 寫作時檢視前文
- 預覽後續章節
- 在長篇文件中保持敘述連貫

### 閱讀時
- 無需翻頁即可連續閱讀
- 無縫捲動體驗
- 適合閱讀小說和長篇文章

### 翻譯時
- 左側原文
- 右側譯文
- 工作時參考下一節內容

### 審校時
- 並排比較章節
- 完整文件上下文
- 高效的校對流程
