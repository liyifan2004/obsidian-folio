# 듀얼 페인 동기화 뷰

듀얼 페인 또는 트리플 페인 동기화 읽기/쓰기 경험을 제공하는 Obsidian 플러그인입니다. 현재 화면과 인접한 콘텐츠를 동시에 볼 수 있으며 완벽한 동기화 스크롤을 제공합니다.

## ✨ 기능

### 📖 2창 모드
- 왼쪽에 **메인 편집기**
- 오른쪽에 **다음 화면** 표시
- 동기화 스크롤
- 연속 독서에 최적

### 📚 3창 모드
- 왼쪽에 **이전 화면** 표시
- 중앙에 **메인 편집기**
- 오른쪽에 **다음 화면** 표시
- 편집 시 완전한 문맥 인식
- 앞뒤 내용을 항상 파악

### ⚡ 스마트 동기화
- 실시간 양방향 스크롤 동기화
- 편집, 미리보기, 소스 모드 지원
- 창 간 중복 줄 수 조정 가능 (0-10줄)
- 원활한 모드 전환

### 🎮 간편한 제어
- 도구 모음 아이콘에서 모드 선택 메뉴
- 빠른 키보드 단축키
- 원클릭 모드 전환
- 창 닫을 때 자동 정리

## 📦 설치

### Obsidian 커뮤니티 플러그인에서
1. 설정 → 커뮤니티 플러그인 열기
2. "Dual Pane Sync View" 검색
3. 설치 및 활성화

### 수동 설치
1. GitHub에서 최신 릴리스 다운로드
2. `.obsidian/plugins/`에 압축 해제
3. 설정 → 커뮤니티 플러그인에서 활성화

## 🚀 사용 방법

### 도구 모음 메뉴
왼쪽 도구 모음의 ◪ 아이콘을 클릭하여 모드 선택 메뉴를 엽니다:

- **2창 모드** - 메인 + 오른쪽 팔로워
- **3창 모드** - 왼쪽 + 메인 + 오른쪽 팔로워
- **중지** - 모든 팔로워 창 닫기

### 명령어
모든 명령어는 명령어 팔레트(Ctrl/Cmd + P)에서 찾을 수 있습니다:

| 명령어 | 설명 |
|---------|-------------|
| 2창 모드 전환 | 2창 모드 켜기/끄기 |
| 3창 모드 전환 | 3창 모드 켜기/끄기 |
| 동기화 읽기 중지 | 모든 팔로워 창 닫기 |
| 양쪽 창 페이지 위로 | 한 페이지 위로 스크롤 |
| 양쪽 창 페이지 아래로 | 한 페이지 아래로 스크롤 |
| 양쪽 창 2페이지 위로 | 두 페이지 위로 스크롤 |
| 양쪽 창 2페이지 아래로 | 두 페이지 아래로 스크롤 |

### 권장 단축키
- **2창 모드**: `Ctrl/Cmd + Shift + D`
- **3창 모드**: `Ctrl/Cmd + Shift + T`
- **중지**: `Ctrl/Cmd + Shift + Q`
- **페이지 위로**: `Ctrl/Cmd + ↑`
- **페이지 아래로**: `Ctrl/Cmd + ↓`

## ⚙️ 설정

### 콘텐츠 중복
창 간 중복 줄 수 조정 (0-10줄):
- **0**: 중복 없음, 깔끔한 페이지 구분
- **2-3**: 권장, 부드러운 독서
- **5-10**: 더 많은 문맥 연속성

### 언어
인터페이스 언어는 Obsidian 설정에서 자동 감지됩니다.

## 🎯 사용 사례

### 글쓰기 시
- 작성 중에 앞 문맥 참조
- 다음 섹션 미리보기
- 긴 문서에서 서술 일관성 유지

### 독서 시
- 페이지 넘김 없이 연속 독서
- 원활한 스크롤 경험
- 소설과 긴 글에 최적

### 번역 시
- 왼쪽에 원문
- 오른쪽에 번역문
- 작업 중 다음 섹션 참조

### 검토 시
- 섹션을 나란히 비교
- 완전한 문서 문맥
- 효율적인 교정 워크플로우
