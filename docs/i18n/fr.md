# Vue Synchronisée Double Volet

Un plugin Obsidian qui permet une expérience de lecture/écriture synchronisée en deux ou trois volets. Visualisez l'écran actuel et le contenu adjacent simultanément avec un défilement parfaitement synchronisé.

## ✨ Fonctionnalités

### 📖 Mode 2 Volets
- **Éditeur principal** à gauche
- **Écran suivant** à droite
- Défilement synchronisé
- Parfait pour la lecture continue

### 📚 Mode 3 Volets
- **Écran précédent** à gauche
- **Éditeur principal** au centre
- **Écran suivant** à droite
- Conscience complète du contexte pendant l'édition
- Voyez ce qui vient avant et après votre position actuelle

### ⚡ Synchronisation Intelligente
- Synchronisation bidirectionnelle en temps réel
- Prend en charge les modes Édition, Aperçu et Source
- Chevauchement ajustable entre volets (0-10 lignes)
- Changement de mode transparent

### 🎮 Contrôles Faciles
- Icône de barre d'outils avec menu de sélection de mode
- Raccourcis clavier rapides
- Changement de mode en un clic
- Nettoyage automatique lors de la fermeture des volets

## 📦 Installation

### Depuis les Plugins Communautaires Obsidian
1. Ouvrir Paramètres → Plugins communautaires
2. Rechercher "Dual Pane Sync View"
3. Installer et Activer

### Installation Manuelle
1. Télécharger la dernière version depuis GitHub
2. Extraire dans `.obsidian/plugins/`
3. Activer dans Paramètres → Plugins communautaires

## 🚀 Utilisation

### Menu de la Barre d'Outils
Cliquez sur l'icône ◪ dans la barre d'outils gauche pour ouvrir le menu de sélection de mode :

- **Mode 2 Volets** - Principal + Suiveur droit
- **Mode 3 Volets** - Gauche + Principal + Suiveur droit
- **Arrêter** - Fermer tous les volets suiveurs

### Commandes
Toutes les commandes se trouvent dans la Palette de commandes (Ctrl/Cmd + P) :

| Commande | Description |
|---------|-------------|
| Activer/Désactiver mode 2 volets | Activer/désactiver la vue double volet |
| Activer/Désactiver mode 3 volets | Activer/désactiver la vue triple volet |
| Arrêter la lecture synchronisée | Fermer tous les volets suiveurs |
| Page précédente (les deux volets) | Défiler vers le haut d'une page |
| Page suivante (les deux volets) | Défiler vers le bas d'une page |
| Page précédente x2 | Défiler vers le haut de deux pages |
| Page suivante x2 | Défiler vers le bas de deux pages |

### Raccourcis Recommandés
- **Mode 2 Volets** : `Ctrl/Cmd + Shift + D`
- **Mode 3 Volets** : `Ctrl/Cmd + Shift + T`
- **Arrêter** : `Ctrl/Cmd + Shift + Q`
- **Page précédente** : `Ctrl/Cmd + ↑`
- **Page suivante** : `Ctrl/Cmd + ↓`

## ⚙️ Paramètres

### Chevauchement du Contenu
Ajustez le nombre de lignes de chevauchement entre volets (0-10 lignes) :
- **0** : Pas de chevauchement, sauts de page nets
- **2-3** : Recommandé, lecture fluide
- **5-10** : Plus de continuité contextuelle

### Langue
La langue de l'interface est automatiquement détectée depuis les paramètres Obsidian.

## 🎯 Cas d'Utilisation

### Pour les Écrivains
- Voir le contexte précédent pendant l'écriture
- Prévisualiser les sections à venir
- Maintenir le flux narratif dans les documents longs

### Pour les Lecteurs
- Lire sans interruptions de changement de page
- Expérience de défilement transparente
- Parfait pour les romans et les articles longs

### Pour les Traducteurs
- Texte source à gauche
- Traduction à droite
- Référencer la section suivante pendant le travail

### Pour les Réviseurs
- Comparer les sections côte à côte
- Contexte complet du document
- Flux de travail de relecture efficace
