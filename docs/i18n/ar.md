# عرض المزامنة ذو النافذتين

ملحق Obsidian يتيح تجربة قراءة/كتابة متزامنة بنافذتين أو ثلاث. عرض الشاشة الحالية والمحتوى المجاور في نفس الوقت مع تمرير متزامن مثالي.

## ✨ الميزات

### 📖 وضع النافذتين
- **المحرر الرئيسي** على اليسار
- **الشاشة التالية** على اليمين
- تمرير متزامن
- مثالي للقراءة المستمرة

### 📚 وضع النوافذ الثلاث
- **الشاشة السابقة** على اليسار
- **المحرر الرئيسي** في الوسط
- **الشاشة التالية** على اليمين
- إدراك كامل للسياق أثناء التحرير
- رؤية ما يأتي قبل وبعد موضعك الحالي

### ⚡ مزامنة ذكية
- مزامنة تمرير ثنائية الاتجاه في الوقت الفعلي
- يدعم أوضاع التحرير والمعاينة والمصدر
- تداخل قابل للتعديل بين النوافذ (0-10 أسطر)
- تبديل وضع سلس

### 🎮 تحكم سهل
- أيقونة شريط الأدوات مع قائمة اختيار الوضع
- اختصارات لوحة مفاتيح سريعة
- تبديل الوضع بنقرة واحدة
- تنظيف تلقائي عند إغلاق النوافذ

## 📦 التثبيت

### من ملحقات مجتمع Obsidian
1. افتح الإعدادات → ملحقات المجتمع
2. ابحث عن "Dual Pane Sync View"
3. ثبّت وفعّل

### التثبيت اليدوي
1. قم بتنزيل أحدث إصدار من GitHub
2. استخرج إلى `.obsidian/plugins/`
3. فعّل في الإعدادات → ملحقات المجتمع

## 🚀 الاستخدام

### قائمة شريط الأدوات
انقر على أيقونة ◪ في شريط الأدوات الأيسر لفتح قائمة اختيار الوضع:

- **وضع النافذتين** - الرئيسي + التابع الأيمن
- **وضع النوافذ الثلاث** - الأيسر + الرئيسي + الأيمن
- **إيقاف** - إغلاق جميع النوافذ التابعة

### الأوامر
جميع الأوامر متوفرة في لوحة الأوامر (Ctrl/Cmd + P):

| الأمر | الوصف |
|---------|-------------|
| تبديل وضع نافذتين | تفعيل/تعطيل عرض النافذتين |
| تبديل وضع ثلاث نوافذ | تفعيل/تعطيل عرض النوافذ الثلاث |
| إيقاف القراءة المتزامنة | إغلاق جميع النوافذ التابعة |
| صفحة للأعلى (النافذتين) | التمرير للأعلى بصفحة واحدة |
| صفحة للأسفل (النافذتين) | التمرير للأسفل بصفحة واحدة |
| صفحتان للأعلى | التمرير للأعلى بصفحتين |
| صفحتان للأسفل | التمرير للأسفل بصفحتين |

### اختصارات موصى بها
- **وضع النافذتين**: `Ctrl/Cmd + Shift + D`
- **وضع النوافذ الثلاث**: `Ctrl/Cmd + Shift + T`
- **إيقاف**: `Ctrl/Cmd + Shift + Q`
- **صفحة للأعلى**: `Ctrl/Cmd + ↑`
- **صفحة للأسفل**: `Ctrl/Cmd + ↓`

## ⚙️ الإعدادات

### تداخل المحتوى
ضبط عدد الأسطر المتداخلة بين النوافذ (0-10 أسطر):
- **0**: بدون تداخل، فواصل صفحات واضحة
- **2-3**: موصى به، قراءة سلسة
- **5-10**: استمرارية سياق أكبر

### اللغة
يتم اكتشاف لغة الواجهة تلقائيًا من إعدادات Obsidian.

## 🎯 حالات الاستخدام

### للكتاب
- رؤية السياق السابق أثناء الكتابة
- معاينة الأقسام القادمة
- الحفاظ على التدفق السردي في المستندات الطويلة

### للقراء
- القراءة بدون انقطاعات تقليب الصفحات
- تجربة تمرير سلسة
- مثالي للروايات والمقالات الطويلة

### للمترجمين
- النص المصدر على اليسار
- الترجمة على اليمين
- الرجوع إلى القسم التالي أثناء العمل

### للمراجعين
- مقارنة الأقسام جنبًا إلى جنب
- سياق المستند الكامل
- سير عمل مراجعة فعّال
